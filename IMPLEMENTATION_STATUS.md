# Notion-Replica

A Notion-inspired workspace app with nested pages, block-based editing, search, favorites, and persistent local storage.

## Quick start

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Notes

- The project is intentionally isolated from the existing production site at `https://rudolfwesterholm.com/`.
- It uses local browser storage for persistence and is not intended for multi-user production deployment.
